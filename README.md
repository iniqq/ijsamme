# Lunge Swap (Fabric, Minecraft 26.2)

Complete project. Upload EVERYTHING in this folder (including the hidden .github folder)
to a GitHub repo; the Action builds it. Download the jar from the run's Artifacts
(use the one WITHOUT "-sources").

Needs: Fabric Loader, Fabric API, Java 25. Mod Menu optional (for the settings screen).
Controls -> "Lunge Swap" sets the key (default R). Delay 5-100 ticks in Mod Menu.
